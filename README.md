# قراصنة البحر — أونلاين

لعبة قراصنة ثلاثية الأبعاد تشتغل في المتصفح (جوال وكمبيوتر)، وكل لاعب عنده جزيرته الخاصة.

## وش فيها
- **جزيرتك**: قلعة وبيوت ومزارع ومنشرة ومنجم ومخزن وحانة وثكنة وحوض سفن وجرس إنذار ومنارة وخزنة. كل مبنى يزيد السكان أو الإنتاج.
- **الدفاعات**: مدافع بحرية ومدافع سلاسل ومنجنيق ناري ومورتر وأبراج رماة ومدفع رشاش ودخان الطوطم وزيت مغلي وسلسلة الميناء وألغام بحرية، وفخاخ مخفية (حفرة، شبكة، برميل بارود، أشواك) وخندق تماسيح، وسور ببوابتين.
- **الحرّاس**: حرس القلعة، طاقم المدافع، رماة الأسوار، الكلاب الحارسة، رجال الإطفاء، الغطّاسين الحرّاس، الفرسان — والمقاتلون من السكان عند دق الجرس، وحرّاس الكنز عند الخزنة.
- **25 نوع قرصان**: بحّار، مبارز، قرصان ببندقية، فني تصليح، مراقب، بسيفين، مدافع، طبيب، طباخ، نهّاب، مدرّع، رامي سكاكين، عازف طبل، الخطّاف، رامي البارود، الملّاح، حامل الراية، هيكل عظمي، الحارق، صياد الحيتان، الجاسوس، قاتل الظل، الغطّاس المخرّب، مروّض الحيوانات، ساحر الفودو، العملاق.
- **الأسطول**: سلوب، بريغانتين، فرقاطة، غليون — مع تطوير الهيكل والمدافع والأشرعة والطاقم، ولون الشراع وتمثال المقدمة، والسفن الثانية ترافقك كمرافقين.
- **العلم**: ارسم علمك بنفسك (24×16)، ويطلع على سفنك وقلعتك. عضو الكلان يطلع علم قائده في زاوية علمه.
- **الكلانات**: اسم الكلان يطلع فوق اسمك كهاشتاق، شات، رتب، خزنة تزيد الإنتاج، وتعزيزات لجزر الأعضاء، وزيارة جزرهم.
- **التحالفات والغدر**: الغدر بحليف يخليك «غدّار» 24 ساعة وعلى راسك مكافأة.
- **الغزو**: اغزُ جزيرة قبطان ثاني، انزل بطاقمك، دمّر دفاعاته وارفع علمك فوق قلعته. درع حماية بعد الغزو، وسجل وانتقام.
- **وحوش البحر**: سفينة الأشباح، الأخطبوط العملاق، وقافلة الملك — يتشارك فيها الكل والغنيمة على قد الضرر.
- **المواسم**: ترتيب بالشرف كل أسبوع وجوائز لأول ثلاثة.

## التشغيل
```
npm start            # السيرفر على المنفذ PORT (الافتراضي 8080)
python3 client/build.py   # يبني server/public/index.html من client/
npm test             # اختبار البروتوكول (يحتاج سيرفر شغّال على 8091)
```
البيانات تنحفظ في `/data/world.json` (أو `DATA_DIR`). على Railway اربط Volume على `/data`.
